# NOS Data & Solution — GitHub Pages

Website tĩnh gồm HTML + CSS + JavaScript, không cần backend.

## Cách triển khai

1. Tạo repository GitHub tên `nosdatasolution.github.io`.
2. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
   - thư mục `assets/`
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main` và thư mục `/root`.
6. Lưu lại. Website sẽ có tại:
   https://nosdatasolution.github.io/
